# 🍱 週末作り置き献立

共働き家庭向けに、**週末にまとめて作る平日（月〜金）の夕食**の献立を提案し、買い物リストまで作るスマホ向け Web アプリです。
レシピ提案には Google AI Studio の **Gemini API** を使います（APIキーがなくても内蔵レシピで動きます）。

## できること

| 画面 | 機能 |
| --- | --- |
| 🗓️ 献立 | 月〜金をカレンダー形式で表示（主菜は肉=赤・魚=青、副菜=緑）。冷蔵／冷凍の日を自動で割り当て（タップで切替）。日ごとに「食べる人」を切り替えると分量が自動調整（例：娘が食べない日）。料理ごとに別案・レシピ帳から選択・曜日入れ替え。日曜の**作り置き段取り**も生成 |
| 🛒 買い物 | 1週間分の材料を合算し、カテゴリ別のチェックリストに。**在庫を差し引いた量**を表示（例：豚こま 500g 必要・在庫 300g → 200g）。手動追加、LINE 等に貼れるテキストコピー |
| 📦 在庫 | 家にある食材を量付きで登録。調味料は「常備品」としてワンタップ登録（買い物リストから除外）。在庫の肉・魚は献立提案でも優先 |
| 📚 レシピ帳 | 使ったレシピが自動で残る。★お気に入り／🔁毎週必ず入れる／🚫今後入れない。料理名から AI でレシピ化して登録、手動登録も可 |
| ⚙️ 設定 | Gemini APIキー・モデル、家族構成と量（未就学児 0.5 など）、主菜の好み（鶏もも・むね・ささみ、サバ・ホッケ・鮭…を 👍／👎）、アレルギー・要望、バックアップ |

- **レシピの選び方**: 「新しいレシピ」「バランス（約4割を過去のレシピから）」「定番中心（過去・お気に入り優先）」から選べます。
- **子ども向け**: 各レシピに未就学児（3〜6歳）向けの取り分けタイミングや味付けの調整が付きます。
- 分量はすべて「大人4人分」で保存し、その日食べる人数に合わせて計算します。

## 使い方

### 1. 公開する（GitHub Pages・無料）

1. このリポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする
2. `main` ブランチにマージすると自動で公開されます（`https://<ユーザー名>.github.io/memo/`）
3. スマホで開き、共有メニューから **「ホーム画面に追加」** するとアプリのように使えます

### 2. Gemini APIキーを設定する

1. [Google AI Studio](https://aistudio.google.com/apikey) で APIキーを作成
2. アプリの ⚙️設定 → 「APIキー」に貼り付け →「接続テスト」
3. モデルは既定で `gemini-3.8-flash`（2026年9月GA）。「モデル一覧を取得」で使えるモデルから選べます

> APIキーはその端末のブラウザ内（localStorage）にだけ保存され、Google の API 以外には送信されません。バックアップファイルにも含まれません。

### 3. 毎週の流れ

1. （在庫があれば）📦在庫に登録
2. 🗓️献立 →「献立を作る」。気に入らない料理はタップして「別の案にする」
3. 娘さんが食べない日は、その日の「娘」ボタンをオフ
4. 🛒買い物リストを見ながらチェック
5. 日曜に「段取りを作る」を見ながらまとめて調理

## ローカルで動かす

ビルド不要の静的サイトです。

```bash
npm start        # http://localhost:8080 で起動（python3 が必要）
npm test         # 献立・分量・買い物リストのロジックのテスト
```

## 構成

```
index.html            画面の枠
css/style.css         デザイン（ダークモード対応）
js/app.js             画面描画と操作
js/planner.js         献立の組み立て・分量計算・買い物リスト集計
js/prompts.js         Gemini へのプロンプトと応答スキーマ
js/gemini.js          Gemini API クライアント
js/data.js            食材カタログ・内蔵レシピ
js/store.js           端末内への保存
sw.js                 オフライン用キャッシュ
```

データは端末内に保存されます。別の端末に移すときは ⚙️設定 の「バックアップを書き出す／読み込む」を使ってください。
